# Viral trajectory simulations

R scripts used to simulate individual viral load and Ct trajectories for SARS-CoV-2, IAV, IBV, and RSV.

The simulations account for parameter uncertainty and inter-individual variability and generate viral trajectories and peak viral kinetics for each virus.

## Scripts

- `simulate_COVID_trajectories.R`: SARS-CoV-2
- `simulate_IAV_trajectories.R`: Influenza A virus
- `simulate_IBV_trajectories.R`: Influenza B virus
- `simulate_RSV_trajectories.R`: Respiratory syncytial virus
